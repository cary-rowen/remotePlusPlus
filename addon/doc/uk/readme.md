# Віддалене керування++

Розширює Віддалене керування NVDA функціями продуктивності для досвідчених користувачів.

## Можливості

### Менеджер з'єднань

Швидко зберігайте, упорядковуйте та підключайтеся до часто використовуваних віддалених сеансів.

* Упорядкування з'єднань за групами
* Пошук з'єднань за назвою або хостом
* Підключення одним кліком зі збереженого списку
* Копіювання посилання на з'єднання до буфера обміну

### Зміна режиму керування

Миттєве перемикання між керуванням іншим комп'ютером і підпорядкованим режимом без відключення від сеансу.

### Підключення до типового сервера

Швидке підключення за допомогою жесту до налаштованого сервера автоматичного з'єднання.

## Менеджер з'єднань

Менеджер з'єднань надає зручний інтерфейс для керування віддаленими з'єднаннями.

### Список гарячих клавіш

| Дія | Клавіша |
|-----|---------|
| Під'єднатися у зворотньому режимі | `Shift+Enter` |
| Перемістити з'єднання вгору | `Alt+Up` |
| Перемістити з'єднання вниз | `Alt+Down` |
| Редагувати з'єднання | `F2` |
| Видалити з'єднання | `Delete` |
| Вибрати все | `Ctrl+A` |
| Копіювати посилання | `Ctrl+C` |

### Контекстне меню

Натисніть правою кнопкою миші на з'єднанні для доступу до додаткових параметрів:

* Під'єднатися / Під'єднатися у зворотньому режимі
* Редагувати
* Копіювати посилання
* Встановити для автоматичного з'єднання
* Перемістити вгору / Перемістити вниз
* Видалити

## Гарячі клавіші

| Команда | Жест |
|---------|------|
| Відкрити менеджер з'єднань | `NVDA+Control+Shift+N` |
| Змінити режим керування | `NVDA+Control+Shift+W` |
| Під'єднатися до типового сервера | Не призначено |

## Пункти меню

Усі функції також доступні з меню Віддаленого керування NVDA:

* Менеджер з'єднань...
* Змінити режим керування
* Під'єднатися до типового сервера (відображається лише якщо налаштовано автоматичне з'єднання)

## Аудіо з малою затримкою

Аудіо з малою затримкою передає звук керованого комп'ютера через
`NVDARemoteAudioServer`. Автоматично використовується поточний хост Remote,
фіксований аудіопорт `6838` і наявний ключ Remote. Під час створення з'єднання
аудіо вимкнене, а редактор з'єднання не містить аудіоналаштувань.

У меню Remote Access є два незалежні пункти:

* Слухати звуки типового пристрою виведення Windows на віддаленому комп'ютері
* Слухати віддалений мікрофон

Пункти доступні лише на керуючому комп'ютері. Вибір надсилає запит керованому
комп'ютеру; обидва джерела можна ввімкнути одночасно, після чого вони змішуються
на керованому комп'ютері. На ньому мають бути встановлені Remote++ і вбудований
аудіомодуль. Якщо використовується старий Remote, немає Remote++ або аудіомодуля,
аудіо буде недоступним чи запит завершиться тайм-аутом, але Remote-з'єднання
залишиться активним. Типову клавіатурну комбінацію для аудіо не призначено.

У Налаштуваннях NVDA → Remote++ можна вибрати буфер відтворення (мінімальний,
типово; 10, 20, 40 або 80 мс), загальний бітрейт (64, 96 типово, 192 кбіт/с),
канали (моно або типове стерео) та режим передавання. Режим малої затримки
використовує пакети по 10 мс (типово), збалансований — по 20 мс.
Збалансований режим зменшує накладні витрати пакетів, але додає час очікування.
Частота дискретизації фіксована: 48 кГц. Мінімальний буфер не означає нульову затримку.
Налаштування спільні для всіх з'єднань. Застосування короткочасно перезапускає
активне прослуховування зі збереженням джерел, але не вмикає вимкнене аудіо.
На обох комп'ютерах потрібен Remote++ з підтримкою Opus; повернення до старого
формату PCM немає. Звичайне віддалене керування й мовлення залишаються доступними.

Аудіо стискається всередині NVDA за допомогою включеної x64 DLL libopus,
без встановлення додаткового середовища. Декодований звук відтворюється блоками по 5 мс. Аудіопротокол
не шифрується; використовуйте довірену мережу або VPN.
