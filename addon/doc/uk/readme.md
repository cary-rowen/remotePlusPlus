# Віддалене керування++

Розширює Віддалене керування NVDA функціями продуктивності для досвідчених користувачів.

## Можливості

### Менеджер з'єднань

Швидко зберігайте, упорядковуйте та підключайтеся до часто використовуваних віддалених сеансів.

* Упорядкування з'єднань за групами
* Пошук з'єднань за назвою або хостом
* Підключення одним кліком зі збереженого списку
* Копіювання посилання на з'єднання до буфера обміну

### Зміна режиму керування

Миттєве перемикання між керуванням іншим комп'ютером і підпорядкованим режимом без відключення від сеансу.

### Підключення до типового сервера

Швидке підключення за допомогою жесту до налаштованого сервера автоматичного з'єднання.

## Менеджер з'єднань

Менеджер з'єднань надає зручний інтерфейс для керування віддаленими з'єднаннями.

### Список гарячих клавіш

| Дія | Клавіша |
|-----|---------|
| Під'єднатися у зворотньому режимі | `Shift+Enter` |
| Перемістити з'єднання вгору | `Alt+Up` |
| Перемістити з'єднання вниз | `Alt+Down` |
| Редагувати з'єднання | `F2` |
| Видалити з'єднання | `Delete` |
| Вибрати все | `Ctrl+A` |
| Копіювати посилання | `Ctrl+C` |

### Контекстне меню

Натисніть правою кнопкою миші на з'єднанні для доступу до додаткових параметрів:

* Під'єднатися / Під'єднатися у зворотньому режимі
* Редагувати
* Копіювати посилання
* Встановити для автоматичного з'єднання
* Перемістити вгору / Перемістити вниз
* Видалити

## Гарячі клавіші

| Команда | Жест |
|---------|------|
| Відкрити менеджер з'єднань | `NVDA+Control+Shift+N` |
| Змінити режим керування | `NVDA+Control+Shift+W` |
| Під'єднатися до типового сервера | Не призначено |

## Пункти меню

Усі функції також доступні з меню Віддаленого керування NVDA:

* Менеджер з'єднань...
* Змінити режим керування
* Під'єднатися до типового сервера (відображається лише якщо налаштовано автоматичне з'єднання)

## Вимоги

* NVDA 2025.1 або новіша версія з увімкненим вбудованим віддаленим керуванням
