# Remote++

增强 NVDA 远程访问功能，为高级用户提供更高效的操作体验。

## 功能

### 连接管理器

快速保存、整理和连接常用的远程会话。

* 使用分组整理连接
* 按名称或主机搜索连接
* 从列表一键连接
* 复制连接链接到剪贴板

### 交换控制模式

在控制另一台计算机和允许远程控制本机之间即时切换，无需断开连接。

### 连接到默认服务器

使用手势快速连接到已配置的自动连接服务器。

## 低延迟音频传输

Remote++ 可以通过 [NVDARemoteAudioServer](https://github.com/haitun001/NVDARemoteAudioServer) 转发远程音频。需要在运行 NVDA 内置远程访问服务的主机上部署该服务端，并开放 TCP 和 UDP `6838` 端口。Remote++ 会自动复用当前远程访问连接的服务器地址和密钥。

音频默认关闭。控制方可以从 NVDA 内置远程访问菜单中开启音频功能。控制方和被控端都需要安装支持音频功能的 Remote++，并通过 NVDA 内置远程访问建立连接。

### 收听远程系统声音

“收听远程系统声音”会将被控端所选系统声音设备的声音传输到控制方。被控端初始使用 Windows 默认输出设备。

如果所选设备也播放 NVDA 语音，Remote++ 会暂停被控端原有的远程访问语音反馈，避免重复朗读。停止收听、音频中断或无法收到有效音频后，原有的远程访问语音反馈会恢复。

### 语音通话

“语音通话”会在控制方和被控端之间建立双向音频传输：

* 被控端的麦克风音频传输到控制方。
* 控制方的麦克风音频传输到被控端。

每一端都通过本机的默认输出设备播放对方的麦克风音频。系统声音和语音通话可以同时启用，并分别使用独立的音频设置。

双方都可以在 **NVDA 设置 → Remote++** 中选择本机麦克风；被控端还可以选择要收听的系统声音设备。所选设备不可用时，会改用 Windows 默认设备。如果默认设备在传输中发生变化，需要重新开启对应的音频功能。

### 音频设置

在 **NVDA 设置 → Remote++** 中，系统声音和语音通话各有一组独立设置：

| 设置 | 可选值 |
| --- | --- |
| 播放缓冲 | 最小缓冲（默认）、10、20、40、80 毫秒 |
| 音频比特率 | 64、96（默认）、192 kbps |
| 音频声道 | 单声道、立体声（默认） |
| 传输模式 | 低延迟：每包 10 毫秒（默认）；均衡：每包 20 毫秒 |

音频使用 Opus 编码，采样率固定为 48 kHz。默认配置为立体声、96 kbps 和每包 10 毫秒。增加播放缓冲可以减少网络抖动造成的断续，但会增加播放延迟。较低的比特率可以减少网络流量，但会降低声音细节。均衡模式可以减少数据包数量，但会增加等待时间。

音频传输设置由控制方选择，音频设备由本机选择。这些设置对所有连接生效，保存在连接管理器偏好中，独立于 NVDA 的配置。保存或应用更改后，正在传输的音频会短暂重启。

通过 TeleNVDA 或旧版 NVDA Remote 建立的连接不提供这些音频控制。使用旧版 Remote++ 的对端仍可进行普通远程控制和朗读，但不能传输音频。同一时间只有一个控制方可以使用远程音频；使用远程音频时，远程访问通道中只能有一台被控端。如果另一台被控端加入，音频会停止。音频协议不提供加密，请只在可信网络或 VPN 中使用。

## 连接管理器

连接管理器提供了一个便捷的界面来管理您的远程连接。

### 列表快捷键

| 操作 | 快捷键 |
|------|--------|
| 以反向模式连接 | `Shift+回车` |
| 上移连接 | `Alt+上光标` |
| 下移连接 | `Alt+下光标` |
| 编辑连接 | `F2` |
| 删除连接 | `Delete` |
| 全选 | `Ctrl+A` |
| 复制链接 | `Ctrl+C` |

### 上下文菜单

右键单击连接可访问更多选项：

* 连接 / 以反向模式连接
* 编辑
* 复制链接
* 设置为自动连接
* 上移 / 下移
* 删除

## 快捷键

| 命令 | 手势 |
|------|------|
| 打开连接管理器 | `NVDA+Control+Shift+N` |
| 交换控制模式 | `NVDA+Control+Shift+W` |
| 连接到默认服务器 | 无 |
| 连接到上一个已保存的连接 | 无 |
| 连接到下一个已保存的连接 | 无 |
| 收听远程系统声音 | 无 |
| 语音通话 | 无 |

## 菜单项

以下功能也可通过 NVDA 内置远程访问菜单使用：

* 连接管理器...
* 交换控制模式
* 收听远程系统声音
* 语音通话
* 连接到默认服务器（仅在已配置自动连接时显示）

## 要求

* NVDA 2026.1 或更高版本，需启用 NVDA 内置远程访问
* 在运行 NVDA 内置远程访问服务的主机上运行 NVDARemoteAudioServer，并监听 6838 端口
* 控制方和被控端都安装 Remote++
* Windows；音频在 NVDA 内使用自带的 comtypes、pycaw 和 WavePlayer，以及插件附带的 x64 Opus 库运行，无需额外安装运行环境

## 安全性

为最大限度确保安全并防止意外访问，该插件在安全桌面（如 UAC 提示、Windows 登录界面）上将被禁用。
